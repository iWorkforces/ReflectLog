## Test Patterns

### Pure Function Tests

Most utility functions are pure and don't require mocking:

```python
def test_normalize_scores_basic():
    """Test basic min-max normalization."""
    scores = np.array([0.1, 0.5, 0.9], dtype=np.float64)
    normalized = normalize_scores_minmax(scores)

    assert normalized[0] == 0.0  # min -> 0
    assert normalized[2] == 1.0  # max -> 1
```

### Security Tests

Test that secrets are properly hidden:

```python
def test_secret_string_hides_value():
    """SecretString should hide value in repr/str."""
    secret = SecretString("my-api-key")

    assert "my-api-key" not in repr(secret)
    assert "my-api-key" not in str(secret)
    assert secret.get_secret_value() == "my-api-key"
```
