# stubs/tantivy/

Type stubs for the tantivy-py library.

## Purpose

Type stubs for the tantivy Python binding, used for full-text search in ReflectLogMCP.

## Usage in Project

Used by `reflectlog/infrastructure/tantivy_engine.py` for:
- Index creation and management
- Document schema definition
- Search query execution
- Soft-delete/tombstone functionality

## Key Components

- `Index` - Main index class
- `SchemaBuilder` - Schema definition
- `Searcher` - Query execution
- `Writer` - Document insertion
- `Document` - Individual document representation

## Note

Provides minimal stubs for tantivy APIs used in the project. Full tantivy API coverage is not provided.
