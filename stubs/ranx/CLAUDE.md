# stubs/ranx/

Type stubs for the ranx library - RRF fusion ranking.

## Purpose

Type stubs for the ranx library used for Reciprocal Rank Fusion (RRF) in hybrid search.

## Usage in Project

Used by `reflectlog/application/memory/fusion/ranx_fusion.py` for:
- `fuse()` function type hints
- Ranking result types
- Fusion configuration types

## Note

Provides minimal stubs for ranx functions used in RRF fusion. Full ranx API coverage is not provided.
