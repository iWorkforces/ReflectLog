# stubs/usearch/

Type stubs for the usearch library - HNSW vector search.

## Purpose

Type stubs for the usearch library used for semantic vector search with HNSW algorithm.

## Usage in Project

Used by `reflectlog/infrastructure/usearch_engine.py` for:
- Index creation and management
- Vector insertion
- Similarity search (exact and approximate)
- Index persistence

## Key Components

- `Index` - Main HNSW index class
- Scalar and vector types
- Metric types (cosine, euclidean, etc.)

## Note

Provides minimal stubs for usearch APIs used in the project. Full usearch API coverage is not provided.
