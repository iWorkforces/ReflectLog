# stubs/numba/core/

Type stubs for numba.core JIT compiler components.

## Purpose

Type stubs for numba's core JIT compilation functionality:
- JIT decorator types
- Compilation context types
- Type system stubs

## Usage in Project

Used by `reflectlog/application/utils/numba_utils.py` for:
- `@njit` decorator hints
- Parallel processing types (`prange`)
- Numerical array operations

## Note

These stubs provide minimal type coverage for the numba functions actually used in the project. Full numba API coverage is not provided.
