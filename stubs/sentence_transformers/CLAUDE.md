# stubs/sentence_transformers/

Type stubs for the sentence-transformers library.

## Purpose

Type stubs for the sentence-transformers library used for text embeddings.

## Usage in Project

This directory contains stubs for alternative embedding providers. The project currently uses:
- Primary: `LangchainQwenEmbeddings` (qwen3_embedding.py)
- Alternative: sentence-transformers for local embeddings

## Note

Currently stubs-only - the project uses Langchain for embedding generation by default.
